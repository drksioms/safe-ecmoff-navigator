# SAFE-ECMOFF Navigator

救急・集中治療の医療者が、プロトコールのStepに沿って組入基準と次の実務を確認する静的Webアプリです。

## 各Stepの使い方

1. **Step 1：組入れ** — 基本適格性と離脱試験可能な状態を確認します。入力に基づく「適格：組入れ候補」「不適格」「現時点の条件未達」「情報不足」を表示します。**適格となった直後、同意取得前に大政へ必ず連絡してください。** その後に説明・同意、EDCでの正式な組入れへ進みます。同意状況は同じStep内で確認します。
2. **Step 2：離脱試験** — 正式な組入れ後24時間以内に開始。印刷済み用紙に開始前・開始30分後・成功判断時（開始後1〜3時間）の日時と実測値を記録します。用紙の記録項目と失敗時記録も参照できます。組入日時・開始予定実績による日本時間の期限確認は任意です。
3. **Step 3：ランダム割付** — Flow weaning成功直後にEDCで実測値を入力して割付。Conventional群／PCRTO追加群の分岐を表示します。PCRTO群は開始前・開始15分後・成功判断時（0.5〜1時間）に印刷済み用紙で記録します。
4. **Step 4：ECMO離脱** — 試験クリア後2日以内の抜去と、抜去24時間後のデータ記録を案内します。悪化時は過去の達成を引き継がず再評価します。

Step 2〜4は手順の参照画面です。次のStepの画面を開く操作は、正式な組入れ・試験成功・割付を意味しません。

## 入力と判定

- Step 1のECMO流量は2.0±0.2 L/min（1.8〜2.2、両端を含む）。全共通指標を1時間以上満たしたことは医療者が明示的に確認します。観察開始・終了日時の入力欄は設けません。現在値やタイマーだけでは継続達成としません。
- 心機能は `(LVEF≧20% または CI≧2.2) かつ (TAPSE≧10mm または PAPi≧0.9)`。各行の一方が達成なら他方の欠測は妨げになりません。
- 未分画ヘパリンは禁忌の場合に除外。APTT延長等による現在未投与のみでは除外しません。
- VISの5剤欄は常時表示し、投与量から自動計算します。**ユーザー指定により薬剤欄の空欄のみ0扱い**です。空欄の扱いを画面にも表示します。他の未回答・不明を0や正常扱いにはしません。負値・非数値は計算不可。「投与量が不明」も選べます。
- 薬剤投与量は体重換算後の値。バソプレシンはU/kg/minです。薬剤変更で継続確認や同意確認を取り消します。
- 入力変更後は再判定します。同意未取得は臨床的適格性と別に扱い、参加拒否とは区別します。

正式な同意、EDC登録、ランダム割付を代行しません。「適格」は入力に基づく研究組入れ候補の意味で、ECMO離脱可能・安全という断定ではありません。医療者が原資料と現在の状態を確認し最終判断してください。

## 情報の扱い

患者氏名・患者ID・生年月日・自由記載の患者情報は入力しません。入力はメモリのみで、再読み込みで消えます。localStorage、外部DB、解析サービス、外部AI送信、患者入力のログ・URL出力はありません。コピーは利用者操作時のみ。コピー文には正式登録未実施と参照資料を含み、コピー後は利用者が管理してください。

参照は配布資料KM081426と第1回班会議（表紙2026/10/28）。ユーザー指定により班会議資料を優先し、個別確認を反映しています。医学的条件の出典と個別確認の記録は、ローカルの内部対応表に保持しています。資料照合文書と画面キャプチャはGitの追跡対象から除外しています。画面上の資料名・ページ表示は省略しています。

## 起動・確認

Node.js 22以降とnpmをインストールし、このフォルダで順番に実行します。

```sh
npm install
npm run dev
```

表示されたローカルURLを開きます。終了はControl+C。フォルダ名の「:」による開発配信の制約があるため、devは本番ビルドのローカルプレビューです。コード変更後は停止して再実行してください。

```sh
npm run typecheck
npm test
npm run build
```

本番出力はdistです。
